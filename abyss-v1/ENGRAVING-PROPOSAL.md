# 装備刻印システム（採用仕様）

2026-11-10: プレイヤー向け草案を採用。刻印は30種類・品質I～Vの5段階。品質で効果量が変化し、難易度別の品質上限は30階 III・50階 IV・100階 V。入手はダンジョン報酬、変異で上位品質の抽選率が変動する。装備ランク1～10と刻印品質は独立し、装備ランクによる装着制限は設けない。

装備強化は `+1～+10` を廃止し、装備レアリティで刻印スロット数を決定する。装備ランクR1～R10は基本能力・ドロップ上限を決める仕組みとして維持する。

## 刻印の基本ルール案

- 強化素材はプラグイン専用の「刻印石」として報酬から入手する。既存の通常サバイバルアイテムと混在しない。
- 装備を選び、空き枠へ刻印石を装着する。効果はその装備を使用・装備中のみ発揮する。
- ロビーの専用GUIで無料で取り外せる。取り外した刻印石は消滅せず倉庫に戻り、別装備へ再利用可能。
- 攻略中の刻印変更は不可。分解、強化値継承、失敗・破壊システムは導入しない。
- 例: 剛力の刻印（武器の物理攻撃力）、守護の刻印（防具の防御力）、魔導の刻印（魔導書の魔力）、生命の刻印（最大HP）、迅速の刻印（職業スキルCD）。
- 同じ名前の刻印は1装備に1個まで。刻印の品質で効果量が変化する。職業と武器種による相性は自由で、特定職業しか装着できない刻印は作らない。
- スキルクールタイム短縮合計の上限は30%、被ダメージ軽減合計の上限は35%。多段攻撃に対する発動クールダウンや回復上限を設ける。
- 取得時は未確定報酬、通常撤退で倉庫へ確定。死亡時の未確定分全損ルールを維持する。

## 実装時のデータ構造案

- 刻印石の所有インスタンスID・効果・数値はSQLiteで永続化。
- 装備インスタンスIDと枠番号に刻印石インスタンスIDを紐付ける。
- 装備レアリティ変更の可能性を考え、枠数減少時に余剰刻印を自動で倉庫へ戻す。
- GUIとSQLの装着・解除処理はトランザクション化し、アイテム消失や複製を防止する。
- 通常インベントリの27スロット一括クリアは行わない。

## 初期実装

- 刻印石は既存の `abyss_pending` → `abyss_inventory` の確定報酬フローを使用する。装着中も石自体は倉庫内の永続レコードとして保持する。
- `abyss_engraving_slots` で装備インスタンスID／枠番号／刻印石IDを永続化し、取り外し時も石のレコードを消さない。
- GUIは「装備選択→空き枠への装着／装着済み枠からの取り外し」。戦闘中の操作は拒否し、同種の刻印重複と同一石の二重装着を拒否する。
- 30種類の刻印候補、品質I～V、難易度別品質上限、戦闘イベントによる初期効果を用意。効果量や状態異常の発動率は実機テストで調整する。
