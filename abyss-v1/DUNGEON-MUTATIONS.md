# ダンジョン変異（初期実装）

ダンジョン入場時には変異を選ばない。次のフロアへ移動するとき、EASY 18% / NORMAL 28% / HARD 38%で抽選し、当選したらリーダーが3候補から1つ選ぶ。変異はその挑戦中に累積する。EASY最大1個、NORMAL最大2個、HARD最大3個。
同一変異の重複は禁止。相性が厳しい組み合わせ（巨大化と再生、治癒阻害と生命減衰、疾風と増殖）は候補に同時出現しない。

変異に当選した移動では、選択が終わるまで移動先フロアの生成を開始しない。選択後に確認GUIを表示し、リーダーが確定して次のフロアへ移動する。抽選に外れた場合は通常どおり移動する。
選択状態はランID単位でSQLiteの `abyss_run_mutations` に保存する。攻略終了時に削除する。
**既存プラグインはラン全体の再起動復帰を実装していないため、サーバー再起動時の攻略再開は非対応**。

| 変異 | 効果 | 追加報酬抽選率 |
| --- | --- | ---: |
| 狂暴化 | 敵攻撃+30% | 15% |
| 鉄壁 | 敵防御+40% | 15% |
| 巨大化 | 敵HP+50% | 15% |
| 疾風 | 敵移動速度+25% | 15% |
| 吸血 | 敵が与えたダメージの10%分を回復 | 20% |
| 再生 | 5秒ごとに最大HPの2%を回復 | 20% |
| 治癒阻害 | イベント経由の回復量-50% | 20% |
| 魔力枯渇 | MP自然回復-50% | 15% |
| 脆弱 | 敵からの被ダメージ+25% | 20% |
| 呪縛 | 鈍足Iの付与 | 10% |
| 生命減衰 | 最大HP-20% | 20% |
| 精鋭化 | 通常敵の20%をHP1.5倍の精鋭にする | 25% |
| 増殖 | 戦闘・強敵フロアの敵数+30% | 20% |
| 深淵の祝福 | 高ランク装備の抽選重み倍率1.5 | 0% |
| 混沌 | 60秒ごとに敵へ強化ポーションをランダム付与 | 30% |

追加報酬抽選率は選択中の変異を加算（上限80%）。宝箱報酬と通常フロア報酬ごとに1回、追加の装備を抽選する。
ランク上限（EASY R5 / NORMAL R8 / HARD R10）は変えない。レアリティは従来どおり独立して抽選。

注意:
- 複雑な変異は仮調整。特に呪縛は現時点で鈍足I相当で、移動速度-15%の厳密な再現ではない。
- 治癒阻害は `EntityRegainHealthEvent` に反応する。直接 `setHealth` する既存処理は対象外。
- 一部の敵強化・ポーション効果は既存のカスタム与ダメージ計算と相互作用するため、Paper実機での数値調整が必要。
- 通常サバイバルのインベントリは変更しない。
