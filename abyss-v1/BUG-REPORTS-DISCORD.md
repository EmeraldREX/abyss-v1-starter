# Discord Webhookによる不具合報告（v0.6.0）

## 使い方（プレイヤー）
1. 専用ロビー・ダンジョンでメインメニューの「不具合を報告」をクリック。代わりに `/abyss report` でも開けます。
2. 「不具合を報告する」をクリック。チャットに不具合の内容を入力します（最大800文字）。
3. 入力した文章は全体チャットに流れず、確認GUIが開きます。
4. 内容を確認して「Discordへ送信」をクリック。書き直し・破棄もできます。
5. チャット入力を止める場合は `cancel` と入力します。

Discordに送信される情報:
- 報告者のMinecraft名とUUID
- 現在のワールド、攻略中なら階層・難易度・フロア種別
- 不具合本文と送信日時

迷惑投稿防止のため同じプレイヤーからの送信間隔は120秒、本文は800文字まで。送信失敗時は送信内容を保持し、プレイヤーに再試行を促します。Webhook送信はHTTP非同期処理で、Paperのメインスレッドをブロックしません。

## 設定方法（管理者）
1. Discordで報告先のテキストチャンネルを開き、「チャンネルを編集」→「連携サービス」→「ウェブフック」から新規Webhookを作成します。DiscordのUIによって表記が多少異なります。
2. 「Webhook URLをコピー」して安全に保管します。
3. **サーバー上の** `plugins/AbyssDungeon/config.yml` に以下を追加します。初回生成時はデフォルト設定に追加されますが、以前からある設定ファイルには自動追記されない場合があります。

```yaml
bug-reports:
  webhook-url: 'https://discord.com/api/webhooks/WEBHOOK_ID/WEBHOOK_TOKEN'
```

4. Paperサーバーを**再起動**して新しい設定を読み込みます。
5. `/abyss report` からテスト送信し、Discordの指定チャンネルに届くか確認します。

Webhook URLを空欄のままにすると報告機能は無効です。
**Webhook URLはパスワード相当です。GitHubに実URLをコミットしたり、スクリーンショットに写したりしないでください。** 漏れた場合はDiscord側でWebhookを削除・再作成してください。

## 仕様・確認事項
- Webhook URLは `https://discord.com/api/webhooks/...` または `https://discordapp.com/api/webhooks/...` のみ受け付けます。安全のため任意URLは設定できません。
- Discordの `@everyone` 等へのメンションは送信時に抑止します。
- Webhookの削除、無効なURL、Discord側の制限、ネットワーク障害で送信に失敗する場合があります。サーバーログにはHTTPステータスのみ出力しURLや本文は出しません。
- 送信は運営チャンネルに共有されるので、プレイヤーには個人情報・パスワード等を書かないよう案内してください。
- 既存の装備、倉庫、通常インベントリ、ワールドや報酬のDB保存は変更しません。
- **Gradleビルド・Paper実機テストは未実施**です。導入前に必ずテストしてください。
