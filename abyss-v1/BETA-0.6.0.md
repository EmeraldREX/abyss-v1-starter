# 深淵の迷宮 ベータ版 v0.6.0

## プレイヤー向け
- 専用ロビーでメニューアイテムを右クリック、または `/abyss menu` を入力。
- メインメニューの **冒険ガイド（本）** から遊び方とルールを10章で確認。
- 職業・装備・魔法・パーティを準備して難易度を選んで入場する（1～4人）。
- EASY は30階、NORMAL は50階、HARD は100階。10階ごとに区間を進める。
- 通常戦闘・強敵・ボス・探索・宝箱・イベント・休憩などのフロアを攻略する。
- 武器はホットバー5番目。職業スキルはFキーか、しゃがみ＋右クリックで発動する。
- 魔法は2枠（ホットバー6・7番目）。職業による使用制限、消費MP、クールタイムあり。
- レベルアップで獲得した強化ポイントは**戦闘中にGUIを開かず蓄積**し、フロア目標達成後にまとめて選べる。
- メインメニュー **成長・強化** で現在の成長内容、未使用ポイントを確認できる。ロビーでは閲覧のみ。
- 死亡時は今回の未確定報酬を失う。正規撤退は休憩フロア・ボス撃破後のみ。
- 報酬を確定して倉庫に保存した装備は次回以降再利用可能。レベル・成長ボーナスは攻略ごとにリセット。

## 管理者・テスター向け権限
本番用コマンドとテスト専用コマンドを分離しました。

テスト専用: `/abyss next`, `/abyss leave`, `/abyss level`, `/abyss learn`,
`/abyss equiptest`, `/abyss rewardtest`, `/abyss lobbybuild`.

- プレイヤー名 `EmeraldREX91` はこれらを使用できます。
- そのほかのプレイヤーは **OPであるだけでは使用できません**。
- Bukkitパーミッション `abyss.test` は `default: false` です。
- LuckPermsで対象者だけに許可する例: `/lp user <プレイヤー名> permission set abyss.test true`
- `/abyss lobby` は通常のロビー移動用（攻略中は移動できません）。`/abyss retreat` は正規の撤退手段です。
- `/abyss leave` は未確定報酬を破棄する危険なテスト用強制退出です。

## 注意
- 仕様とUIはベータ段階で変更される可能性があります。
- 成長GUIは倉庫や報酬GUIが開いている間は自動的に上書きしません。その場合はメインメニューの成長・強化から選択してください。
- ボス撃破後のパークとレベルアップ強化は、それぞれの選択画面から取得します。成長を先に選びます。
- ビルドとPaper実機テストは未実施。既存サーバーに導入する前にバックアップしてください。
