# フロア戦闘とパーク修正

- レベル5ごとのパーク取得権は戦闘中でも蓄積するが、GUIはフロアクリア後のみ開く。`/abyss perks` で戦闘中に開こうとしても拒否する。
- 成長ポイントの選択が残っているときはそちらを優先し、パークの候補は保持する。
- 通常敵候補を14種に拡大。ヴィンディケーター、エンダーマン、エヴォーカー、ウィッチ、ウィザースケルトン、ボグドなどを追加。
- ボスは10階区切りごとにラヴェジャー → アイアンゴーレム → ヴィンディケーター → エンダーマン → エヴォーカーを巡回。
- ダンジョン内のエヴォーカーはヴェックス召喚の詠唱だけをキャンセルし、牙の魔法攻撃は残す。
- ダンジョン内のエンダーマンは割り当てマップ範囲外へのテレポートをキャンセルする。
- 中立Mobでも挑戦中のプレイヤーを標的として設定する。

敵の攻撃頻度、敵サイズとマップの通路幅、ボス攻撃パターンはPaper実機テストが必要。
