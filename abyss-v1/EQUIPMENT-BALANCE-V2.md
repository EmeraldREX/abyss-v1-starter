# 装備・職業・報酬の追加調整

- 装備定義のランク倍率を R1～R10 = `1 / 1.2 / 1.5 / 1.85 / 2.3 / 2.85 / 3.5 / 4.3 / 5.3 / 6.5` に拡大。既存865種類は攻撃・防御を再調整。
- 魔導書を30種類（`abyss_book_01`～`abyss_book_30`）追加。オフハンドに装備でき、魔力とMPが上昇。合計895種。
- 魔導書はランクごとの候補から抽選し、他の装備に比べて基本重み2.5倍。職業適性のある装備は追加で1.25倍。
- 装備適性ボーナスは基本能力と装備個体の追加能力に25%。職業自身の基本能力にはかからない。

| 職業 | 得意装備 |
| --- | --- |
| 戦士 | 剣・斧・防具 |
| 魔法使い | 棍棒（杖）・魔導書 |
| 僧侶 | 魔導書・盾 |
| 弓使い | 弓 |
| 聖騎士 | 剣・盾・防具 |
| 暗殺者 | 爪・鞭 |
| 狂戦士 | 槌・斧 |
| 武闘家 | 拳・爪 |

## 育成

- レベル5、10、15…到達時にパーク候補を生成。ボス後の選択機会も残す。
- 同時に複数のパーク選択機会を得た場合は待ち行列に積む。
- 新しい経験値テーブルは `leveling.effective-xp-base=65`、`leveling.effective-xp-growth=1.15`。旧設定を残した環境でも変更を適用できるよう、新キーを使用。

## 探索とイベント

- 探索: 3つの手掛かりのうち正しい道をリーダーが選ぶ。成功するとパーティ全員に追加装備、失敗時は毒罠。
- イベント: 生命の祭壇（HP30%）、魔力の泉（MP全快）、封印された宝箱（追加装備、25%でHP10%の罰）。
- どちらも選択が終了するまでフロアをクリアできない。パーティの未確定報酬として既存SQLiteに保存する。
