# 第12段階: ラン内パーク・初期倉庫・ロビー・常時HUD・HP/MP回復

- 10階ごとに剛力(+5攻撃)、堅守(+5防御)、生命(+20最大HP)から1つ選択。`/abyss perks` で未選択の画面を再表示。ラン終了で消去。10階到達時に表示し、ボス撃破の有無には連動していない仮仕様。
- 初回ログイン時、倉庫に剣・杖・盾・魔導書・防具4種・指輪・護符・回復薬を各1個。付与済みはDBに記録して二重配布を防ぐ。既存プレイヤーにも初回の本バージョン起動・ログイン時に付与。
- ロビーで自然/外部由来のMobスポーンを禁止。ダンジョンではプラグインがCUSTOMで出す敵以外を禁止。通常サバイバルワールドには影響しない。
- 新規ロビーワールド生成時のみ17x17広場、4本の柱、ゲートを作成。既存ロビーは上書きしない。`lobby-build-on-create: false` で無効化。
- HUDは全ワールドで表示。ほかのスコアボード系プラグインとは表示枠が競合しうる。
- 攻略開始/退出時に最大HPとMPまで回復。通常ワールドに戻ったら最大HPを20に復元。死亡後はロビーで復活して回復。
- ラン内パークはメモリ管理であり、サーバー再起動後の攻略復元は未実装。
- Java 25/Paperでのビルド・実機動作確認は未実施。
